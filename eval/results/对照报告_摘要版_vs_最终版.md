# 摘要版 vs 最终版（话题片段 RAG）记忆对照报告

## 实验设置（两版完全一致）

- 提示词：`persona-v4`，模板指纹 `8ff6a376c870e3ee`，固定骨架 347 字
- 记忆预算：800 字
  - 摘要版：1 份滚动摘要（800 字）
  - 最终版：常驻画像 200 字 + 每题检索 3 段 × 200 字
- 最近窗口：6 条消息
- 情绪/关系状态：同一套提取回路
- 探针：128 条，六类；温度 0；每题基于同一份对话快照独立提问
- 反幻觉、人格一致、摘要漂移的判定规则完全相同

对话脚本不同，这是两套架构的本质差异：

- **摘要版**：134 轮连续对话，一份摘要一路滚动压缩
- **最终版**：100 个场景、约 300 轮；每个场景只聊一件事、3 轮左右，场景结束视为 30 分钟无消息，
  这 3 轮压成 ≤200 字片段写入知识库。100 个话题片段，检索粒度更细

## 主结果

| 类别 | 摘要版 | 最终版 | 变化 |
| --- | ---: | ---: | ---: |
| 事实召回 direct | 67/87 = 77.0% | **84/87 = 96.6%** | +19.6pp |
| 信息更新 update | 5/6 = 83.3% | 5/6 = 83.3% | 持平 |
| 干扰辨别 distractor | 10/12 = 83.3% | **12/12 = 100%** | +16.7pp |
| 反幻觉 anti_halluc | 16/16 = 100% | 16/16 = 100% | 持平 |
| 摘要幻觉 summary_drift | 1/2 = 50% | **2/2 = 100%** | +50pp |
| 人格一致 persona | 5/5 = 100% | 5/5 = 100% | 持平 |
| 两次都答对 | 9/10 | **10/10** | +10pp |
| 两次答案一致 | 9/10 | 9/10 | 持平 |

## 记忆距离分层（direct）

| 距离 | 摘要版 | 最终版 |
| --- | ---: | ---: |
| 极远（>100 轮） | 21/21 = 100% | 58/61 = 95.1% |
| 远（71-100 轮） | 19/23 = 82.6% | **10/10 = 100%** |
| 中（31-70 轮） | 19/29 = 65.5% | **12/12 = 100%** |
| 近（≤30 轮） | 8/14 = 57.1% | **4/4 = 100%** |

两版失效方向相反：

- 摘要版是**尾部截断**：新事实追加在 800 字摘要末尾，超限就从尾部切掉，越近越差。
- 最终版是**画像容量限制**：常驻画像只有 200 字，最早期的事实会被后来的信息挤掉；中近段靠检索补回来。

## 成本

| 项目 | 摘要版 | 最终版 |
| --- | ---: | ---: |
| 对话生成总量 | 114,697 | 174,091 |
| 记忆压缩总量 | 88,002（63 次摘要） | 76,644（100 段 + 100 次画像） |
| 状态提取总量 | 47,774 | 104,675 |
| 对话总 token | 250,473 | 355,410 |
| 对话轮数 | 134 | 300 |
| **单轮平均** | **1,869** | **1,185（-36.6%）** |
| 128 条探针 | 124,241 | 87,867（-29.3%） |

最终版总 token 更高是因为脚本从 134 轮扩到 300 轮；按单轮比，反而便宜 36.6%。
原因是不用每两轮重压一份 800 字摘要，改成每个场景压一次 200 字，最近窗口也只有 6 条。

## 关键结论

1. **事实召回 77.0% → 96.6%**，且反幻觉保持 100%，没有用"放弃拒答"换准确率。
2. **近期记忆 57.1% → 100%**，这是摘要版最严重的失效点（尾部截断），检索把它修好了。
3. **摘要幻觉 50% → 100%**。摘要版会把"父亲已去世"这种自己编出来的内容当事实继续用；最终版的片段按场景生成、来源可追，没有把这条写进去。
4. **单轮成本下降 36.6%**：片段按话题压缩，比反复重压长摘要更省。
5. 剩下的唯一错误是信息更新（豆豆年龄）：新旧两段都在库里，查询"几岁"时检索命中了旧段"两岁"，没命中后来的"三岁生日"。这说明更新型事实需要额外的时间权重或失效标记，是下一步可以改进的点。

## 可写进简历的表述

> 长期记忆陪伴系统 · 两套记忆架构对照评测
> - 单会话架构：按 30 分钟空闲自动切段，每段压缩为 ≤200 字记忆单元，配合 200 字常驻画像与 bge-small-zh + BM25 混合检索，固定 800 字记忆预算。
> - 自建 100 个真实场景（约 300 轮）的对话脚本与 128 条六维探针（召回 / 更新 / 干扰 / 反幻觉 / 摘要漂移 / 人格一致性），温度 0、同提示词、同预算做 A/B。
> - 结果：事实召回 77.0% → 96.6%，近期记忆 57.1% → 100%，干扰辨别 83.3% → 100%，摘要幻觉 50% → 100%，单轮 token 成本下降 36.6%。
