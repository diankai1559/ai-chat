# 摘要版 vs 最终版（话题片段 RAG + 标签去重）记忆对照报告

## 实验设置（两版完全一致）

- 提示词：`persona-v4`，模板指纹 `8ff6a376c870e3ee`，固定骨架 347 字
- 记忆预算：800 字
  - 摘要版：1 份滚动摘要（800 字）
  - 最终版：常驻画像 200 字 + 每题检索 3 段 × 200 字
- 最近窗口：6 条消息
- 情绪/关系状态：同一套提取回路
- 探针：128 条，六类；温度 0；每题基于同一份对话快照独立提问
- 反幻觉、人格一致、摘要漂移的判定规则完全相同

对话脚本不同，这是两套架构的本质差异：

- **摘要版**：134 轮连续对话，一份摘要一路滚动压缩
- **最终版**：100 个场景、约 300 轮；每个场景只聊一件事、3 轮左右，场景结束视为 30 分钟无消息，
  这 3 轮压成 ≤200 字片段写入知识库。100 个话题片段，检索粒度更细

最终版在检索层额外做了两件事：

- 片段带结构化标签：`time / place / people / emotion / topic / open_loops / importance`，
  标签由生成摘要的同一次 JSON 调用顺带产出，不额外增加请求
- 检索打分加入标签命中和时间偏好（查询含“现在 / 今年 / 几岁 / 进展 / 搬 / 涨”时时间权重从 0.12 提到 0.30），
  并对词面重合 ≥0.6 或向量相似度 ≥0.85 的片段做去重

## 主结果

| 类别 | 摘要版 | 最终版 | 变化 |
| --- | ---: | ---: | ---: |
| 事实召回 direct | 67/87 = 77.0% | **85/87 = 97.7%** | +20.7pp |
| 信息更新 update | 5/6 = 83.3% | **6/6 = 100%** | +16.7pp |
| 干扰辨别 distractor | 10/12 = 83.3% | 11/12 = 91.7% | +8.4pp |
| 反幻觉 anti_halluc | 16/16 = 100% | 16/16 = 100% | 持平 |
| 摘要幻觉 summary_drift | 1/2 = 50% | **2/2 = 100%** | +50pp |
| 人格一致 persona | 5/5 = 100% | 5/5 = 100% | 持平 |
| 两次都答对 | 9/10 | **10/10** | +10pp |
| 两次答案一致 | 9/10 | 8/10 | -10pp（措辞不同但都对） |

合计：摘要版 124/128（96.9%），最终版 125/128（**97.7%**）。

## 记忆距离分层（direct）

| 距离 | 摘要版 | 最终版 |
| --- | ---: | ---: |
| 极远（>100 轮） | 21/21 = 100% | 59/61 = 96.7% |
| 远（71-100 轮） | 19/23 = 82.6% | **10/10 = 100%** |
| 中（31-70 轮） | 19/29 = 65.5% | **12/12 = 100%** |
| 近（≤30 轮） | 8/14 = 57.1% | **4/4 = 100%** |

两版失效方向相反：

- 摘要版是**尾部截断**：新事实追加在 800 字摘要末尾，超限就从尾部切掉，越近越差。
- 最终版是**画像容量限制**：常驻画像只有 200 字，最早期的事实会被后来的信息挤掉；中近段靠检索补回来。

## 成本

| 项目 | 摘要版 | 最终版 |
| --- | ---: | ---: |
| 对话生成总量 | 114,697 | 174,091 |
| 记忆压缩总量 | 88,002（63 次摘要） | 76,644（100 段 + 100 次画像） |
| 状态提取总量 | 47,774 | 104,675 |
| 对话总 token | 250,473 | 355,410 |
| 对话轮数 | 134 | 300 |
| **单轮平均** | **1,869** | **1,185（-36.6%）** |
| 128 条探针 | 124,241 | 88,335（-28.9%） |

最终版总 token 更高是因为脚本从 134 轮扩到 300 轮；按单轮比，反而便宜 36.6%。
原因是不用每两轮重压一份 800 字摘要，改成每个场景压一次 200 字，最近窗口也只有 6 条。
标签和摘要同一次调用产出，不额外增加成本。

## 关键结论

1. **事实召回 77.0% → 97.7%**，且反幻觉保持 100%，没有用“放弃拒答”换准确率。
2. **近期记忆 57.1% → 100%**，这是摘要版最严重的失效点（尾部截断），检索把它修好了。
3. **信息更新 83.3% → 100%**：加入时间偏向后，“豆豆现在几岁”能正确取到“三岁”那段，不再答旧值。
4. **摘要幻觉 50% → 100%**：摘要版会把“父亲已去世”这种自己编出来的内容当事实继续用；最终版按场景生成、来源可追，没有把它写进去。
5. 单轮成本下降 36.6%，探针成本下降 28.9%。

## 还没解决的点

- 同一个更新事实换一种问法仍会翻车：问“豆豆现在几岁”答对三岁，问“豆豆今年几岁”却答了两岁（干扰题 D04）。
  说明“新旧两段都在库里”时，BM25 的词面重合还会把旧段拉上来。下一步需要事实级去重或失效标记，而不是片段级去重。
- 忌口题仍会把“花生过敏”当成“不吃香菜”；Kindle 的“落灰很久”没有正面回答。都是检索粒度与措辞覆盖的问题。
- 片段级去重拦不住“同一事实换句式”的重复，问咖啡时仍会拿回两条都在说“美式不加糖”的片段。

## 可写进简历的表述

> 长期记忆陪伴系统 · 两套记忆架构对照评测
> - 单会话架构：按 30 分钟空闲自动切段，每段压缩为 ≤200 字记忆单元并自动打标签（时间/地点/人物/情绪/话题/未完成事项），配合 200 字常驻画像与 bge-small-zh + BM25 混合检索，固定 800 字记忆预算。
> - 自建 100 个真实场景（约 300 轮）的对话脚本与 128 条六维探针（召回 / 更新 / 干扰 / 反幻觉 / 摘要漂移 / 人格一致性），温度 0、同提示词、同预算做 A/B。
> - 结果：事实召回 77.0% → 97.7%，近期记忆 57.1% → 100%，信息更新 83.3% → 100%，摘要幻觉 50% → 100%，单轮 token 成本下降 36.6%。
