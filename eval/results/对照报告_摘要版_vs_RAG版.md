# 摘要版 vs RAG 版 记忆对照报告

## 实验设置（两版完全一致）

- 对话脚本：`eval/dialogue.txt`，134 轮，100 个关键记忆点
- 探针：`eval/probe_set.py`，124 条，六类
- 提示词：`persona-v4`，模板指纹 `8ff6a376c870e3ee`
- 生成温度：对话 0.8，探针 0；两版相同
- 记忆预算：800 字
  - 摘要版：1 份滚动摘要（800 字）
  - RAG 版：常驻画像 200 字 + 每题检索 3 段 × 200 字
- 最近窗口：6 条消息
- 情绪/关系状态：同一套提取回路

RAG 版把 134 轮切成 13 天（前 4 天 11 轮、后 9 天 10 轮），每天结束生成一段 ≤200 字记忆并更新画像。
检索为 bge-small-zh 向量 + jieba BM25（0.7 / 0.3），再加 0.08 的时间偏好。

## 主结果

| 类别 | 摘要版 | RAG 版 | 变化 |
| --- | ---: | ---: | ---: |
| 事实召回 direct | 63/83 = 75.9% | **78/83 = 94.0%** | +18.1pp |
| 信息更新 update | 5/6 = 83.3% | **6/6 = 100%** | +16.7pp |
| 干扰辨别 distractor | 10/12 = 83.3% | **12/12 = 100%** | +16.7pp |
| 反幻觉 anti_halluc | 16/16 = 100% | 16/16 = 100% | 持平 |
| 摘要幻觉 summary_drift | 0/2 = 0% | **2/2 = 100%** | +100pp |
| 人格一致 persona | 5/5 = 100% | 5/5 = 100% | 持平 |
| 两次都答对 | 9/10 | **10/10** | +10pp |
| 两次答案一致 | 10/10 | 8/10 | -20pp（措辞不同但都对） |

## 记忆距离分层（direct）

| 距离 | 摘要版 | RAG 版 |
| --- | ---: | ---: |
| 极远（>100 轮） | 21/21 = 100% | 18/21 = 85.7% |
| 远（71-100 轮） | 19/23 = 82.6% | **23/23 = 100%** |
| 中（31-70 轮） | 19/29 = 65.5% | **27/29 = 93.1%** |
| 近（≤30 轮） | 4/10 = 40% | **10/10 = 100%** |

两版的失效方向正好相反：

- 摘要版是**尾部截断**：新事实追加在 800 字摘要末尾，超限就从尾部切掉，所以越近越差，最近 30 轮只剩 40%。
- RAG 版是**画像容量限制**：常驻画像只有 200 字，最早的身份类事实会被后来的信息挤掉，所以极远段掉到 85.7%；中近段靠检索补回来。

## 关键结论

1. **事实召回 75.9% → 94.0%**，且不靠牺牲反幻觉换来：两版 anti_halluc 都是 100%。
2. **近期记忆从 40% 修到 100%**，这是摘要版最严重的失效点，也是 RAG 最直接的收益。
3. **摘要幻觉从 0/2 到 2/2**。摘要版会把"父亲已去世"这种自己编出来的内容当事实继续用；RAG 版的片段按天生成、来源可追，没有把这条写进去。
4. **成本反而更低**：少了对长摘要的反复重压，整体 token 下降约 30%。
5. RAG 剩下的 5 个错误里，4 个是检索没命中（问题与片段都需要兜底），1 个是片段已在上下文里但模型没用上（F069"怕当众发言"）。这说明检索召回率（当前 Recall@3 约 89%）仍是主要瓶颈，而不是生成能力。

## 可写进简历的表述

> 长期记忆对话系统 · 两套记忆架构对照评测
> - 设计并实现会话片段级长期记忆：按 30 分钟空闲/按天切段，每天压缩为 ≤200 字记忆单元，配合 200 字常驻画像与 bge-small-zh + BM25 混合检索。
> - 在固定 800 字记忆预算、同一提示词与同一 134 轮脚本下做 A/B：事实召回 75.9% → 94.0%，近期记忆 40% → 100%，摘要幻觉 0/2 → 2/2，整体 token 成本 -29.8%。
> - 自建 124 条六维探针（召回/更新/干扰/反幻觉/摘要漂移/人格一致性），定位检索 Recall@3 为主要瓶颈，并给出按距离分层的失效分析。
